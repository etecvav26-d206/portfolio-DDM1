## 📚 Sobre o Repositório

Este repositório reúne atividades, exercícios práticos e projetos desenvolvidos ao longo da disciplina.

O objetivo é registrar a evolução do grupo no desenvolvimento de aplicativos mobile, além de praticar conceitos fundamentais de lógica, interface e construção de aplicações.
